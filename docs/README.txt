Relic Tool 使用说明 / User Guide

版本号：1.0.0

从你已有的遗物中，按所选角色和词条寻找《艾尔登法环 黑夜君临》配装。

绿色免安装，程序本身完全离线，不联网、不上传数据。仅分析存档副本，不修改原始存档或游戏文件。设置和存档副本保存在程序文件夹内。

需要 Windows 10 / 11 64 位和 .NET Framework 4.8。

开始使用

1. 完整解压到普通可写文件夹，双击“Relic Tool.exe”。不要直接在压缩包里运行；无需管理员权限。
2. 工具会自动查找存档。请在左下角选择存档来源和角色栏位。没有找到存档时，点击“导入存档”，选择 .sl2 或 .co2 文件。
3. 在左上角选择要配装的游戏角色，再从中间栏搜索、添加词条或预设遗物，合计最多 10 条。
4. 特别需要的条件切换为“必须”，其他保留“想要”。用 ↑ / ↓ 把更重要的同类要求往上排；可以选择数量的项目，按需设置数量。
5. 添加或修改条件后，程序会自动计算。等待完成后，在右侧切换器皿，查看对应的六颗遗物。
6. 点击某颗遗物的“下一个”更换候选，其余五颗保持固定。点击“恢复最优”，还原当前器皿的推荐组合。
7. 点击“显示位置”，按提示的遗物类型、颜色和行列在游戏中查找。白色万能槽不显示位置。

常用操作

- 将鼠标悬停在词条或器皿上，可查看更多词条详情或对比信息。
- 新获得遗物后，等待游戏保存，再点击“刷新”。
- 标题栏“EN / 中”切换语言，“− / +”调整界面大小，共四档。
- 位置窗口支持列表／卡片、置顶和背景透明度调节。贴到屏幕边缘可自动收起，鼠标靠近提示条时展开，移开后收回。
- 没有结果或无法满足全部要求时，先确认存档和栏位是否正确，再尝试减少条件或降低数量。
- 请勿把程序文件夹中的 UserData 随软件分享，其中包含本地设置和存档副本。

English

Version: 1.0.0

Find ELDEN RING NIGHTREIGN relic loadouts for your chosen character and effects, using relics you already own.

Portable and fully offline. The app requires no installation, makes no internet connections, and uploads no data. It reads a copy of your save without modifying the original save or game files. Settings and save copies stay in the program folder.

Requires 64-bit Windows 10 / 11 and .NET Framework 4.8.

Getting started

1. Extract all files to a normal folder you can write to, then open "Relic Tool.exe". Do not run it from inside the ZIP. Administrator access is not required.
2. The tool automatically looks for your saves. Select your save source and character slot at the bottom left. If your save is not found, click "Import save" and select a .sl2 or .co2 file.
3. Choose the game character you want to equip at the top left. Search for and add effects or preset relics in the middle column, up to 10 entries in total.
4. Set your most important requirements to "Required" and leave the others as "Wanted". Use ↑ / ↓ to move more important entries higher within each type. Set the quantity where a quantity selector is available.
5. Adding or changing requirements starts the search automatically. Once it finishes, switch between vessels on the right to view each set of six relics.
6. Click "Next" on a relic to try another candidate while keeping the other five fixed. Click "Restore best" to restore the recommended set for the current vessel.
7. Click "Show locations" and use the displayed relic type, color, row and column to find each relic in the game. Locations are hidden for white universal slots.

Useful tips

- Hover over an effect or vessel to see more effect details or comparison information.
- After obtaining new relics, wait for the game to save, then click "Refresh".
- Use "EN / 中" in the title bar to switch languages. Use "− / +" to choose from four interface sizes.
- The location window supports list/card views, always-on-top mode and background transparency. Drag it to a screen edge to tuck it away. Hover over its tab to reveal it; move the pointer away to hide it again.
- If there are no results or some requirements cannot be met, check the selected save and slot, then try fewer requirements or lower quantities.
- Do not include the UserData folder when sharing the tool. It contains your local settings and save copies.

Updates and feedback

Click the gold leaf icon at the top left to open About. "View updates" opens the release page in your external browser. The app itself does not check for or download updates online.
